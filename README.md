### 문의 등록 시 주의사항

본문, 댓글 및 첨부파일에 다음과 같은 민감정보가 포함되지 않도록 주의해 주세요.

- 애플리케이션 인증정보
  - `client_secret`
  - Application Secret
- 유효기간이 남아 있는 인증 토큰
- 기밀 또는 대외비 정보
- 개인정보 및 계정정보
- 결제 및 지불정보
- 구매자를 식별할 수 있는 주문정보
- 그 밖에 공개 게시가 부적절한 정보
